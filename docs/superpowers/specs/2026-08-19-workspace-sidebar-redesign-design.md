# BloomAI 固定工作区侧栏重构设计

- 日期：2026-08-19
- 状态：已确认方案 A，已实现
- 范围：Renderer 左侧工作区导航、聊天列表、项目树和“更多”浮层

## 1. 背景与目标

BloomAI 当前将 48px 的图标导航栏与约 200px 的聊天/项目列表分成两个侧栏。目标是将其改造成上传参考图所示的统一工作区侧栏：顶部是带文字的快捷入口，中部是聊天和项目列表，底部固定设置入口。

目标约束：

- 默认固定宽度约 320–336px，选定实现值为 328px。
- 不支持用户拖拽调整宽度。
- 不增加折叠侧栏功能或折叠图标。
- 顶部入口顺序固定为：新建聊天、项目、技能、AI 画图、定时任务、更多...
- “项目”是新建项目快捷入口，不是独立项目页面。
- 项目行不显示 `⌘` 等快捷键符号，只显示项目名称和必要的展开/操作控件。
- 设置固定在侧栏最底部，并继续保留为独立入口。

## 3. 设计方案

### 3.1 统一侧栏结构

采用方案 A，新建统一的工作区侧栏概念。侧栏结构为：

```text
WorkspaceSidebar (328px)
├── workspace-navigation
│   ├── 新建聊天
│   ├── 项目
│   ├── 技能
│   ├── AI 画图
│   ├── 定时任务
│   └── 更多...
├── workspace-content (统一滚动区域)
│   ├── 聊天 (N)
│   └── 项目 (N)
│       └── 项目内聊天
└── workspace-settings (固定底部)
```

统一侧栏在主页面布局中保持存在。非聊天页面仍可看到聊天和项目入口；用户点击聊天或项目内聊天时，侧栏将切换到聊天页面并加载对应会话。

原有业务 store、API 和数据结构继续复用，不新增后端接口。

### 3.2 顶部入口映射

| 显示名称 | 行为 | 现有目标 |
|---|---|---|
| 新建聊天 | 创建普通会话、加载消息、切到聊天页 | `createSession` |
| 项目 | 打开创建项目弹窗 | `CreateProjectDialog` |
| 技能 | 切换页面 | `skills` |
| AI 画图 | 切换页面 | `image` |
| 定时任务 | 切换页面 | `schedules` |
| 更多... | 打开浮层菜单 | MCP、文章配图、Personas、Tools |

“项目”创建成功后不强制跳转页面；项目列表刷新、项目区域展开并展开新项目。

### 3.3 “更多...”浮层

浮层菜单项固定为：

1. MCP Servers
2. 文章配图
3. Personas
4. Tools

交互约定：

- 鼠标进入“更多...”时打开。
- 浮层从触发项右侧展开，右边缘与侧栏右边缘对齐。
- 鼠标在触发项与浮层之间移动时保持打开。
- 鼠标离开两者共同区域后关闭。
- 点击触发项可切换打开/关闭，保证触摸板和键盘可用。
- `Enter` / `Space` 打开或关闭；`Escape` 关闭；菜单项支持 Tab 聚焦。
- 点击菜单项后跳转并关闭浮层。
- 浮层使用主题背景、约 12px 圆角、细边框和轻阴影。

### 3.4 聊天列表

- 标题从“最近聊天”调整为 `聊天 (N)`，N 使用后端返回的聊天总数。
- 标题带箭头，点击可折叠/展开。
- 列表继续使用最近会话排序、分页加载、空状态和错误重试。
- 当前会话显示浅灰圆角选中背景。
- 行标题单行省略，时间信息靠右。
- hover 或键盘聚焦时显示重命名和删除操作。
- 从任意页面点击聊天行时切回聊天页并加载消息。
- “更多”继续调用现有 `loadRecentSessions` 分页逻辑。

### 3.5 项目树

- “空间”概念统一改为 `项目 (N)`。
- 项目行不显示 `⌘`，只显示项目名称、展开箭头和 hover 时的新建聊天控件。
- 每个项目展开状态独立维护。
- 项目内聊天保持缩进，复用现有 `SessionRow` 的选择、重命名、删除能力。
- 项目行支持 hover 新建项目聊天。
- 项目列表继续支持加载、错误重试、空状态和“更多项目”。
- 取消项目区域和聊天区域之间的拖拽分隔器，两个区域改为同一个滚动容器中的连续内容。

### 3.6 设置入口

- 设置按钮位于侧栏底部固定区域，不随聊天/项目列表滚动。
- 点击后切到现有 `settings` 页面。
- 保留 `Ctrl/Cmd + ,` 快捷键。

## 4. 组件与样式改动边界

建议将导航行为与现有列表能力组合成统一侧栏组件，优先复用现有子组件，避免重写会话和项目业务逻辑：

- 重构 `NavSidebar` 为统一工作区侧栏，或抽出 `WorkspaceSidebar` 并由 `App.tsx` 使用。
- 将 `ProjectSessionSidebar` 的项目/聊天内容抽出为统一滚动内容，删除区域 resize 状态与 pointer 事件。
- 调整 `RecentSessions` 的标题、布局和跨页面选择行为。
- 调整 `ProjectTree` 的项目行视觉，不添加快捷键符号。
- 更新 `App.tsx`，让统一侧栏在所有页面保持显示。
- 更新 `global.css`：
  - 固定 328px 宽度。
  - 新增文字导航行、统一内容滚动区和底部设置区。
  - 移除/停用旧窄图标栏及 resize 分隔器样式。
  - 增加更多浮层定位、hover 和键盘焦点样式。
  - 沿用现有 light/dark design tokens。

不在本次范围内：

- 后端 API、数据库 schema 和项目数据模型。
- 新建项目弹窗内部字段和目录选择逻辑。
- 会话消息页面内部布局。
- 各功能页面自身的 UI 重构。

## 5. 可访问性与状态

必须覆盖：

- 导航按钮有可读名称和当前页状态。
- 列表标题使用可折叠按钮语义并正确设置 `aria-expanded`。
- 项目行有 `aria-expanded` 和项目名称描述。
- 会话行支持 Tab、Enter 和 Space。
- 更多浮层支持 Escape 关闭并可通过键盘访问。
- 项目、聊天加载中显示 skeleton；错误显示重试；空列表显示空状态。
- 选中状态不能只依赖颜色，应同时保留文本和结构差异。

## 6. 原型与验收

实现后绘制一张与参考图同构的侧栏原型/预览，至少包含：

- 顶部六个入口。
- “更多...”浮层展开态。
- `聊天 (N)` 列表和选中聊天。
- `项目 (N)`、展开项目和项目内聊天。
- 底部设置。
- 固定 328px 侧栏与右侧主内容占位。

验收标准：

- 侧栏默认宽度为 328px，不能拖拽修改。
- 不出现折叠按钮。
- 顶部入口和“更多...”内容与设计一致。
- 项目按钮打开新建项目弹窗。
- 聊天、项目展开/收起、项目内聊天、重命名和删除继续可用。
- 设置固定在底部。
- 现有页面跳转和主题样式不回归。
- 相关 Vitest、类型检查和构建命令通过。
